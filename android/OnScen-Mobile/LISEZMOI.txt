Soundly — Mode d'emploi telephone (msdev)
=========================================

DOSSIER
-------
  OnScen-Mobile/www/  = build PWA mobile pret a servir (copie de apptel)
  Le serveur msdev sur le PC sert ces fichiers sur /tel/


ACCEDER DEPUIS LE TELEPHONE (meme Wi-Fi)
----------------------------------------
  1. Sur le PC : double-clic OUVRIR-SUR-TEL.bat (a la racine du projet)
     ou OnScen-Mobile\LANCER-POUR-TEL.bat

  2. Notez l'URL affichee, par ex. :
     http://192.168.x.x:4080/tel/

  3. Sur le telephone : ouvrez cette URL dans Safari (iPhone) ou Chrome (Android)

  Important :
  - Le PC et le telephone doivent etre sur le meme reseau Wi-Fi
  - L'IP affichee est celle du PC (pas du telephone)
  - Le serveur ecoute en 0.0.0.0 le temps de la session LAN
  - Page QR sur le PC : http://localhost:4080/msdev-mobile?app=tel


INSTALLER EN PWA (ecran d'accueil)
----------------------------------
  iPhone (Safari) :
    1. Ouvrir http://192.168.x.x:4080/tel/
    2. Partager (icone carre + fleche) → « Sur l'ecran d'accueil »
    3. Valider le nom « Soundly »

  Android (Chrome) :
    1. Ouvrir la meme URL
    2. Menu ⋮ → « Ajouter a l'ecran d'accueil » ou « Installer l'application »

  Au 2e lancement, l'app est fluide : assets mis en cache par le service worker.

CAMERA / MICRO (optionnel)
--------------------------
  En HTTP sur le LAN, le navigateur peut bloquer la camera.
  Sur le PC : npm run msdev:https
  Puis sur le telephone : https://192.168.x.x:4080/tel/
  Acceptez le certificat auto-signe une fois.


REBUILD MANUEL
--------------
  npm run mobile:build
  → rebuild apptel + copie dans OnScen-Mobile/www/


DEPANNAGE
---------
  - Telephone ne charge pas : verifier HOST=0.0.0.0 (relancer OUVRIR-SUR-TEL.bat)
  - Cache obsolete : ouvrir http://IP:4080/clear-pwa puis /tel/
  - IP changee : npm run msdev:sync-lan
