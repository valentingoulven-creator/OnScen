## 2. Build cassé — trouvé et corrigé en session (`MODIF 1339`)

**Constat** : `npm run build` dans `web/app` (= `tsc -b && vite build`, le build réellement utilisé par `deploy_zero_downtime.ps1`) échouait avec 5 erreurs TypeScript. Un `npx tsc --noEmit -p tsconfig.json` isolé (utilisé en début de session pour "vérifier vite") **ne les détectait pas**, car le `tsconfig.json` racine est un tsconfig "solution" (`references` uniquement, pas de `files`/`include`) — il ne type-check rien par lui-même. **Piège méthodologique à retenir** : seule la commande de build réelle (`tsc -b`) ou `tsc -b --force` fait foi.

**Cause** : travail non finalisé de la session précédente (MODIF 1334, overlay rayon carte lives) — `MapView.tsx` construit et transmet à `GlobeView` un objet `{ lat, lng, radiusKm }`, mais la prop `livesListRadius` de `GlobeView.tsx` était typée `{ center: [number, number]; radiusKm; unlimitedQuery? }` (copiée par erreur du type de `MapView` au lieu du type réellement transmis), plus un type `MapBounds` non importé et un callback `handleOwnSalonEnded` (`App.tsx`) devenu mort après suppression de son point d'appel ailleurs dans le diff en cours.

**Fix appliqué** (détail complet dans `modification.txt`, `MODIF 1339`) :
- `GlobeView.tsx` : import du type `MapBounds`, retypage de `livesListRadius` en `{ lat, lng, radiusKm } | null`, simplification du `useMemo` associé.
- `App.tsx` : suppression du callback mort `handleOwnSalonEnded`.
- Purge du cache `.tsbuildinfo` (corrompu par des `tsc` interrompus pendant l'audit, masquait une 2ᵉ fausse erreur sur `GLOBE_LIVES_VIEWPORT_RADIUS_KM`).

**Vérifié** : `npm run build` (web/app) → ✅ succès en 1m28s, 0 erreur `tsc`, 0 erreur `vite`. `npm run build` (backend) → ✅.

**Recommandation** : la CI (`.github/workflows/ci.yml`) utilise déjà correctement `tsc -b --noEmit` + `npm run build` — mais elle ne s'exécute que sur push/PR vers `master`/`main`. Comme ce travail vit sur une branche non mergée depuis des semaines, la CI ne l'a jamais validé (voir §7, PROC-3) : c'est ce qui a permis à cette régression de rester invisible jusqu'à cet audit manuel.

### BUG-2 (🟡 à re-vérifier isolé) — `aiAgents.test.ts` timeout

```
commun/backend/src/lib/aiAgents/aiAgents.test.ts > buildDevDataContext
```

`buildDevDataContext()` ne fait que des lectures fichier/RAM synchrones simples (`fs.readFileSync`, agrégats `db.*`) — pas d'I/O réseau.
