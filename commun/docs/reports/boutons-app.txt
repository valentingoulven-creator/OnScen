4. SALON PLEIN ÉCRAN
═══════════════════════════════════════════════════════════
Header :
• ↓ Réduire le salon (chevron seul — MODIF 456) → minimise sur la carte ; barre « Revenir au salon »
• Live (hôte, pas déjà en live) → démarre un live lié au salon
• Arrêter le salon (hôte) → ferme le salon pour tous
• Quitter le salon (auditeur) → quitte la session

Lecture (YouTube) :
• Lecture / Pause → contrôle synchronisé (hôte / mod VIP)
• Suivant → morceau suivant dans la file
• Morceau dans la file → lance ce morceau
• Changer de morceau (recherche hôte) → change immédiatement
• Lire (résultat recherche) → idem
• Ajouter à la file → ajoute sans couper le morceau
• Lancer la playlist → lance une playlist YouTube
• Vidéo on / off (si applicable) → affiche ou masque la vidéo YouTube

Auditeur (MODIF 458) :
• Proposer un morceau (recherche YouTube) → envoie au panneau PROPOSITIONS de l'hôte, pas de lecture directe
• Proposer (bouton) → confirme la proposition
• Formulaire Proposer un morceau (titre/artiste/liens) → proposition manuelle

Panneau host (hôte avec plateforme connectée) :
• Suivant → skip file
• Propositions — Lire → accepte et joue maintenant
• Propositions — File → accepte et ajoute à la file
• Propositions — ✕ → refuse et supprime
• Lien d'invitation → copie le lien de partage

Gérer l'accès (hôte, MODIF 454) :
• Public → salon visible et ouvert à tous
• Invitation → salon sur invitation uniquement
• Cases contacts → sélection des invités potentiels
• Validé → enregistre la liste et envoie notification salon_invite

Chat salon :
• Masquer / Afficher le chat → toggle panneau chat
• Participants (hôte/dev) → liste connectés ; actions mod :
  - Droits mod. / Retirer droits
  - Expulser
  - Bloquer (durée ou permanent)
• Sur un message : ⋮ → Supprimer ; Signaler
• Sur un pseudo : Message privé, Voir profil, Mettre/Retirer VIP, Bannir, Signaler
• Envoyer → poste le message

États spéciaux :
• Réessayer → recharge le salon en erreur
• Retour → session terminée (2 h max)
