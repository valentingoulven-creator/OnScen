# Lettres de soutien Soundy (.docx)

Dix modèles Word, **un fichier par registre d’écriture**, utilisables par tout type d’artiste (personnaliser les `[…]`).

| Fichier | Style |
|---------|--------|
| `01-registre-institutionnel.docx` | Institutionnel |
| `02-registre-convivial.docx` | Convivial |
| `03-registre-professionnel-anglais.docx` | Professionnel (EN) |
| `04-registre-poetique.docx` | Poétique |
| `05-registre-entrepreneurial.docx` | Entrepreneurial |
| `06-registre-academique.docx` | Académique |
| `07-registre-court-reseaux.docx` | Court / réseaux |
| `08-registre-emotionnel.docx` | Émotionnel |
| `09-registre-associatif.docx` | Associatif |
| `10-registre-journalistique.docx` | Journalistique |

Source Markdown : [`../LETTRES-SOUTIEN-SOUNDY-MODELES.md`](../LETTRES-SOUTIEN-SOUNDY-MODELES.md).

## Régénérer les .docx

```powershell
npm install --prefix commun/docs/strategie
npm run lettres-soutien --prefix commun/docs/strategie
```
