## Résumé exécutif

Soundy est le **réseau social** pensé comme un **promoteur d'artistes et d'événements** (application mobile-first, [getsoundy.com](https://getsoundy.com)). Le modèle économique priorise les **sponsors natifs** (45 à 55 % du revenu cible à 24 mois), complétés par les commissions créateurs (pourboires live, abonnements créateurs — **non actifs au lancement**) et les forfaits plateforme **Soundy+ / SoundyUltra** (**roadmap, non effectifs au démarrage**).

**Opportunité** : les annonceurs musique et nightlife cherchent des alternatives aux CPM Meta et Instagram (6 à 18 € en France). Soundy propose un inventaire vertical et géolocalisé, dès **~150 € pour 7 jours** (Carte · Sponso, palier 50 000 inscrits).

**Vision** : ancrage **France → Europe → international** — devenir la référence du réseau social musique live. Soundy **met en visibilité les événements musicaux** sur la carte géolocalisée : concerts, soirées et festivals découverts près de l'utilisateur, du quartier à l'échelle continentale puis mondiale.

## 1. Étude de marché

### 1.1 Problème et positionnement

Les fans dispersent leur attention entre TikTok (découverte), Instagram (social), Shotgun et Resident Advisor (sorties), Spotify et YouTube (écoute). Aucun acteur ne combine **social, carte géolocalisée, écoute partagée, live et monétisation créateur** dans une application verticale pensée pour le mobile.

**Proposition Soundy** : unifier découverte → écoute ensemble → live → événements, avec des formats sponsorisés natifs et non intrusifs. La **carte géolocalisée** assure la **visibilité des événements** : pins concerts et festivals, clusters par ville, découverte par zone — le lien entre communauté en ligne et vie événementielle.

### 1.4 Concurrence

| Acteur | Force | Limite face à Soundy |
|--------|-------|----------------------|
| Instagram / TikTok | Portée, algorithme | Pas de carte événements musique, pas d'écoute synchronisée |
| SoundCloud | Hébergement artistes, communauté créateurs, découverte | Pas de carte ni événements géolocalisés, monétisation limitée côté fan |
| Bandcamp | Vente directe artiste–fan, fidélisation | Orienté e-commerce, pas réseau social grand public ni événements géolocalisés |
| Groover | Promotion artistes (médias, playlists, curateurs) | Service B2B ponctuel, pas d'app sociale ni d'écoute partagée |
| Audius | Social musique décentralisé, rémunération créateurs | Audience niche, pas de carte événements ni salons synchronisés |
| Spotify | Écoute | Social limité, pas d'événements géolocalisés |

**Atouts différenciants Soundy** : salons d'écoute YouTube synchronisés · **visibilité des événements** sur la carte géolocalisée · salons actifs sur la carte · live vidéo · sponsors natifs · pourboires et abonnements créateurs intégrés.

### 1.5 Tendances 2026–2028

- **Hyper-local** : campagnes par ville ou région, avec estimation d'audience par zone.
- **Formats courts** : Reels sponsorisés comme entrée de gamme (~150 € / 7 jours).
- **Mesure de performance** : les annonceurs exigent une preuve d'exposition (reporting campagne).
- **Économie des créateurs** : pourboires live comme revenu complémentaire indépendant des marques.

(function () {
  var root = document.getElementById('tarifSim');
  if (!root) return;
  var tiers = root.querySelectorAll('.tarif-tier-btn');
  var daysInput = root.querySelector('#tarifDays');
  var daysLabel = root.querySelector('#tarifDaysLabel');
  var exposedRange = root.querySelector('#tarifExposed');
  var exposedNum = root.querySelector('#tarifExposedNum');
  var exposedLabel = root.querySelector('#tarifExposedLabel');
  var priceOut = root.querySelector('#tarifResultPrice');
  var noteOut = root.querySelector('#tarifResultNote');

  function activeTier() {
    for (var i = 0; i < tiers.length; i++) {
      if (tiers[i].classList.contains('is-active')) return tiers[i];
    }
    return tiers[0];
  }

  function fmtEuro(n) {
    return Math.round(n).toLocaleString('fr-FR') + ' €';
  }

  function clampExposed(n) {
    var min = parseInt(exposedRange.min, 10);
    var max = parseInt(exposedRange.max, 10);
    return Math.max(min, Math.min(max, Math.round(n)));
  }

  function setExposed(n, syncInputs) {
    var val = clampExposed(n);
    if (syncInputs !== false) {
      exposedRange.value = val;
      exposedNum.value = val;
    }
    exposedLabel.textContent = val.toLocaleString('fr-FR');
    return val;
  }

  function update() {
    var tier = activeTier();
    var cpm = parseFloat(tier.getAttribute('data-cpm'));
    var exposed = setExposed(parseInt(exposedNum.value, 10) || parseFloat(tier.getAttribute('data-exposed')), false);
    var days = parseInt(daysInput.value, 10);
    daysLabel.textContent = days;
    var price = (exposed * days * cpm) / 1000;
    priceOut.textContent = '~' + fmtEuro(price);
    noteOut.textContent =
      'Carte · Sponso · ~' +
      exposed.toLocaleString('fr-FR') +
      ' utilisateurs exposés · ' +
      days +
      ' j · CPM ' +
      cpm.toFixed(2).replace('.', ',') +
      ' € · ' +
      tier.textContent.trim();
  }

  for (var i = 0; i < tiers.length; i++) {
    tiers[i].addEventListener('click', function () {
      for (var j = 0; j < tiers.length; j++) tiers[j].classList.remove('is-active');
      this.classList.add('is-active');
      setExposed(parseFloat(this.getAttribute('data-exposed')));
      update();
    });
  }

  exposedRange.addEventListener('input', function () {
    setExposed(parseInt(exposedRange.value, 10));
    update();
  });

  exposedNum.addEventListener('input', function () {
    if (exposedNum.value === '') return;
    setExposed(parseInt(exposedNum.value, 10));
    update();
  });

  exposedNum.addEventListener('change', function () {
    setExposed(parseInt(exposedNum.value, 10) || parseFloat(activeTier().getAttribute('data-exposed')));
    update();
  });

  daysInput.addEventListener('input', update);
  update();
})();

### 2.7 Coûts d'infrastructure & projection de performance

Soundy fonctionne sur une infrastructure cloud managée (hébergement, base de données, streaming vidéo) facturée à l'usage — **pas de licence logicielle ni de coût fixe par utilisateur**. Le coût technique croît par paliers, bien plus lentement que le revenu.

**Postes de coûts techniques actuels**

| Poste | Rôle | Coût mensuel estimé |
|-------|------|----------------------|
| VPS (API + Node.js) | Hébergement backend, reverse proxy, relais WebRTC | ~8–12 € |
| Base de données PostgreSQL managée | Utilisateurs, messages, fil, salons, événements | ~15 € |
| Domaine getsoundy.com | Nom de domaine + DNS | ~1 € |
| Cloudflare Stream | Diffusion des lives (CDN vidéo, à la consommation) | 0 € fixe + usage |
| LiveKit Cloud | Lives caméra navigateur (quota gratuit puis palier payant) | 0 € fixe + usage |
| Gmail Pro (Google Workspace) | Messagerie professionnelle de l'équipe | ~17 € |
