MeloSong — Générer l'exécutable Windows (msdev.exe)
==================================================

## Prérequis (une seule fois)

1. Node.js 18+ installé sur le PC de compilation
2. Dépendances installées à la racine du monorepo :

   cd backend
   npm install
   cd ../app
   npm install
   cd ..

3. Fichier msdev/.env présent (copiez msdev/.env.example si besoin)

## Compiler

À la racine du projet MeloSong Dev :

   npm run build:exe

Étapes automatiques :
- Build de l'interface React (app → backend/public)
- Compilation TypeScript du backend
- Empaquetage pkg → msdev/release/msdev.exe
- Copie de public/, .env, config.json, data/ dans msdev/release/

## Utiliser l'exe

1. Ouvrez le dossier msdev/release/
2. Double-cliquez msdev.exe (ou Lancer-msdev.bat)
3. Le navigateur s'ouvre sur http://localhost:4080

Ne déplacez pas msdev.exe sans le dossier release/ complet.

## Smartphone depuis l'exe

- Même Wi‑Fi que le PC
- Sur le PC : http://localhost:4080/msdev-mobile (QR + URL)
- Mettez MOBILE_HOST_IP dans release/.env si l'IP du PC change
- Caméra sur téléphone : préférez npm run msdev:https en dev (certificat) ;
  l'exe par défaut est en HTTP (limites navigateur pour la caméra)

## Limites

- Windows x64 uniquement (pas macOS / Linux / App Store)
- Serveur local sur le PC — pas un hébergement cloud
- Pas d'application native iOS/Android dans ce build (voir MOBILE-PWA.txt)

## Dépannage build

- « entry-msdev.js introuvable » → npm run backend:build
- pkg échoue → vérifiez la connexion Internet (télécharge le runtime Node)
- Port 4080 occupé → fermez les autres npm run msdev
