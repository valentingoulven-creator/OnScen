OnScen — Smartphone (PWA + réseau local)
==========================================

## Accès navigateur (recommandé en msdev)

1. Sur le PC : `npm run msdev` ou `npm run msdev:https` (caméra)
2. Même réseau Wi‑Fi que le téléphone
3. URL = IP du PC (pas du téléphone), ex. https://192.168.1.93:4080
   - Fichier msdev/MOBILE-URL.txt
   - `npm run msdev:mobile-url`
   - Page QR : http://localhost:4080/msdev-mobile (PC uniquement)

4. HTTPS : acceptez le certificat auto-signé une fois (voir msdev/HTTPS-ACCES.txt)

## Installer en PWA (« Ajouter à l'écran d'accueil »)

### Android (Chrome)

1. Ouvrez l'URL OnScen sur le téléphone
2. Menu ⋮ → « Ajouter à l'écran d'accueil » ou « Installer l'application »
3. L'icône OnScen apparaît comme une app

### iPhone (Safari)

1. Ouvrez l'URL dans Safari (pas dans une webview tierce)
2. Partager → « Sur l'écran d'accueil »
3. Validez le nom « OnScen »

Conditions : service worker actif (build production / msdev avec app:build),
manifest et icônes servis par le même hôte (localhost ou IP LAN).

## Application native (hors scope actuel)

Pour App Store / Play Store plus tard : Capacitor ou Tauri mobile
en pointant l'API vers votre serveur de production.
En msdev, le PWA + navigateur LAN suffit pour tester.

## Limites

- PWA msdev = raccourci vers le serveur du PC (le PC doit tourner)
- Géolocalisation / caméra : souvent HTTPS requis (msdev:https)
- Pas de push notifications natives sans backend dédié
