—————————— Fenêtre CMD qui se ferme tout de suite ——————————

Symptôme : double-clic sur un .bat, un flash noir, rien à lire.

Cause fréquente : erreur au démarrage (Node absent, mauvais dossier, port 4080
occupé, msdev.exe bloqué) alors que l'ancien script ne faisait pas « pause ».

Fichier à utiliser en priorité (dossier source MeloSong Dev) :
  msdev\Lancer-MeloSong.bat

Il affiche l'URL (http/https localhost:4080), le compte démo, et la fenêtre
reste ouverte avec « Appuyez sur une touche… » en cas d'erreur.

Si le message indique que le port 4080 est déjà utilisé : MeloSong tourne
déjà — ouvrez https://localhost:4080 dans le navigateur ou fermez l'autre instance.

—————————— Redémarrer le serveur (server.exe) ——————————

Racine MeloSong Dev :
  server.exe   — double-clic : libère le port 4080 puis relance le serveur HTTP
  server.bat   — même chose si server.exe manque ou est bloqué par Windows

Générer server.exe : npm run build:server-exe (csc .NET, pas msdev.exe pkg)

Si Smart App Control bloque server.exe : utilisez server.bat (pas d'exe dédié).
Le serveur Node (npm) reste lancé via node.exe signé Microsoft.
