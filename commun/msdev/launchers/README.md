# Launchers Windows (double-clic)

Scripts déplacés depuis la racine. Tous se placent automatiquement à la racine du repo.

| Fichier | Action |
|---------|--------|
| `LANCER-MELOSONG.bat` | Backend msdev :4080 |
| `OUVRIR-SUR-TEL.bat` | Build mobile + URL LAN |
| `ACCES-IPHONE.bat` | Tunnel ngrok + serveur |
| `BUILD-ET-LANCE.bat` | Build prod + ngrok |
| `deploy-prod.bat` | Deploy getsoundy.com |
| `server.bat` | Redémarrer le serveur msdev |

Depuis la racine : `npm run dev` reste la commande recommandée.
